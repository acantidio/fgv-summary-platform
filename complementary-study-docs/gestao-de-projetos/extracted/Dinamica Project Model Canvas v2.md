# Dinamica Project Model Canvas v2
### Dinâmica: Preenchendo o Project Model Canvas

Objetivo:
Nesta dinâmica, os alunos irão escolher um projeto de seu desejo e preencher as principais informações nas colunas do Project Model Canvas. O objetivo é ajudar os alunos a estruturar o projeto de forma clara, conectando as motivações e os resultados esperados, de forma que seja compreensível para todos os envolvidos.

Passos para a Dinâmica:

1. Escolha do Projeto (10 minutos)
Os alunos devem escolher um projeto do qual gostariam de trabalhar durante a dinâmica. Pode ser um projeto real de suas áreas de atuação ou um projeto fictício, como por exemplo um evento, um novo produto ou serviço, ou mesmo um projeto pessoal.

2. Preenchimento do Project Model Canvas (20 minutos)
Cada grupo de alunos irá trabalhar no preenchimento das seguintes colunas do Project Model Canvas para o projeto escolhido:

Gerente do Projeto: Defina quem será o gerente do projeto e quais serão suas principais responsabilidades. Podem escolher um membro do grupo para representar este papel.

Pitch: Desenvolvam uma breve descrição do projeto que comunique de forma clara e concisa o que é o projeto, quem será beneficiado e por que é importante. O pitch deve capturar o interesse dos stakeholders.

Justificativas: Respondam à pergunta: "Por que este projeto é importante?". Quais são os motivos que fazem esse projeto ser relevante para a organização ou para os stakeholders?

Objetivo SMART: Definam o objetivo do projeto utilizando a metodologia SMART (Específico, Mensurável, Atingível, Relevante e com Tempo definido). Este objetivo deve deixar claro o que o projeto pretende alcançar.

Benefícios: Liste os principais benefícios que o projeto trará para a organização ou para os envolvidos. Considere tanto benefícios tangíveis quanto intangíveis.

Produto: Descrevam o produto final do projeto, ou seja, o que será entregue ao final da execução. Pode ser um produto físico, um serviço ou um resultado específico.

Principais Requisitos: Identifiquem os requisitos principais que devem ser atendidos para que o projeto alcance seu objetivo e entregue o produto esperado. Considerem tanto os requisitos técnicos quanto os requisitos de negócio.

Resultado Esperado:
Os alunos vão desenvolver habilidades de planejamento, definição de objetivos e comunicação de projetos, praticando o uso do Project Model Canvas para estruturar as ideias principais de um projeto de forma concisa e bem-organizada. Isso ajudará a criar uma base sólida para qualquer projeto que venha a ser desenvolvido no futuro.

Resumo do Assunto:
O Project Model Canvas é uma ferramenta visual poderosa desenvolvida pelo professor José Finocchio para ajudar você a organizar e estruturar os principais elementos de um projeto. Ela facilita o alinhamento de ideias e permite definir os principais componentes do projeto de maneira clara e colaborativa. O Canvas foi desenvolvido como um modelo simples e eficaz para comunicar a essência do projeto em um único quadro visual.

O Project Model Canvas possui 15 campos, cada um com uma função específica para garantir que todas as informações importantes do projeto sejam consideradas. Esses campos, na ordem apresentada, são:

Gerente do Projeto: Defina quem será o gerente do projeto, indicando quem será o responsável pelo seu sucesso e condução.

Pitch: Desenvolva uma breve descrição do projeto que comunique de forma clara e concisa o que é o projeto.

Justificativas (Passado): Explique a razão pela qual o projeto é importante, incluindo os problemas que ele pretende resolver ou as oportunidades que visa explorar.

Objetivo SMART: Descreva o objetivo do projeto utilizando o conceito SMART (Específico, Mensurável, Atingível, Relevante e com Tempo definido), deixando claro o que o projeto pretende alcançar.

Benefícios (Futuro): Liste os principais benefícios do projeto, tanto tangíveis quanto intangíveis, explicando o valor que ele trará para a organização ou para os stakeholders.

Produto: Descreva o produto final do projeto, ou seja, o que será entregue ao final da execução. Pode ser um produto físico, um serviço ou um resultado específico.

Requisitos: Defina os requisitos principais que precisam ser atendidos para garantir que o produto ou resultado cumpra suas funções e satisfaça as necessidades do cliente.

Stakeholders Externos e Fatores Externos: Identifique todas as partes interessadas que estão fora da organização, como clientes, parceiros ou fornecedores, bem como fatores externos, tais como clima, pandemia, economia, leis, que podem influenciar este projeto.

Equipe: Defina a equipe que estará envolvida na execução do projeto, especificando papéis e responsabilidades de cada membro.

Grupo de Entregas: Defina as principais entregas do projeto, detalhando o que será realizado e quando.

Premissas: Liste as premissas que precisam ser consideradas como verdadeiras para o desenvolvimento do projeto, mesmo que não tenham sido comprovadas no momento.

Restrições: Defina as limitações do projeto, sejam elas relacionadas ao prazo, ao orçamento ou a qualquer outro recurso.

Riscos: Enumere os riscos principais que o projeto pode enfrentar e que precisam ser monitorados e mitigados.

Linha do Tempo: Estabeleça a cronologia do projeto, indicando os principais marcos e prazos para as entregas.

Custos: Estime os custos principais do projeto, ajudando a estabelecer um orçamento adequado para sua execução.

Com essa dinâmica, você terá a oportunidade de aprender a planejar de forma clara e prática, definindo os principais pontos que sustentam o projeto, como justificativas, objetivos, benefícios e requisitos. Com essa prática, você estará mais preparado para comunicar suas ideias e entender os elementos essenciais que fazem parte de um projeto bem-sucedido. Essa visão estruturada é essencial para garantir que todas as partes interessadas compreendam e se engajem com o projeto, contribuindo para sua efetiva realização.
