# Dinamica Priorização de Projetos
### Dinâmica: Priorizando com WSJF - Weighted Shortest Job First"

Objetivo

O grupo recebe 6 projetos de uma empresa e precisa posicioná-los no Quadrante WSJF, decidindo quais fazer primeiro, quais podem esperar e quais devem ser descartados neste ciclo.

O Quadrante WSJF - em resumo

O WSJF prioriza projetos que entregam muito valor com pouco esforço. Para cada projeto, o grupo responde duas perguntas:

Qual é o valor gerado para o negócio, para os clientes ou para a operação?

Qual é o esforço necessário: custo, tempo, complexidade?

| Quadrante | Valor | Esforço |

| 1 - Faça agora | Alto | Baixo |

| 2 - Faça a seguir | Baixo | Baixo |

| 3 - Faça mais tarde | Alto | Alto |

| 4 - Não faça agora | Baixo | Alto |



Cenário: Clínica Saúde Plena

| Contexto: A Clínica Saúde Plena é uma rede de clínicas de saúde ocupacional com 3 unidades e 120 colaboradores. Atende empresas clientes com exames admissionais, periódicos e demissional. A diretoria aprovou R$ 800 mil para projetos no próximo ano e a equipe consegue tocar no máximo 2 projetos simultaneamente. |

Passos para a Dinâmica

1. Votação individual silenciosa (5 min)

Cada membro lê os 6 cartões e anota, para si, em qual quadrante colocaria cada projeto. Use apenas: Q1 / Q2 / Q3 / Q4. Não discutam ainda.

2. Discussão e consenso (20 min)

Projeto a projeto, cada membro compartilha seu voto. Quando houver divergência, quem votou diferente explica o raciocínio. O grupo negocia até chegar a um consenso. Para cada projeto, registrem:

Valor: Alto ou Baixo

Esforço: Alto ou Baixo

Quadrante: Q1 / Q2 / Q3 / Q4

3. Posicionando no quadrante e definindo o portfólio (10 min)

Transfiram os projetos para o quadrante na folha de preenchimento. Depois, com o limite de R$ 800 mil e 2 projetos simultâneos, definam quais entram no ciclo.

Anotem o número do projeto dentro do quadrante correspondente.

Identifiquem quais do Q1 cabem no orçamento e na capacidade disponível.

Se sobrar orçamento, algum projeto do Q3 pode ser antecipado?

4. Apresentação e debate (5 min)

Cada grupo mostra seu quadrante e anuncia os 2 projetos do ciclo. O professor lança uma pergunta ao grupo: "O projeto 04 (IA) ficou em qual quadrante de vocês? Por quê?"

Resultado Esperado

| O que você vai desenvolver nesta dinâmica |

| Capacidade de estimar valor e esforço de forma ágil e argumentada. |

| Prática na aplicação do Quadrante WSJF como ferramenta de priorização. |

| Compreensão de que priorizar é escolher — inclusive decidir o que não fazer neste ciclo. |

| Percepção de como diferentes perfis profissionais enxergam valor de formas distintas. |
